# People Space — Born From a Burst

A 65-second cinematic cosmic teaser for **People Space**, an HR / employee experience platform.
Eight scroll-driven chapters, custom voice-overs, ambient cosmic pad, and a hero reveal.

## What's in this repo

| File | What it is |
|---|---|
| `index.html` | Auto-redirects to the presentation (so the bare site URL just works) |
| `people-space-cosmic.html` | The full interactive HTML presentation (the main artifact) |
| `1.mp3` … `8.mp3` | Voice-over narration, one per chapter |
| `ambient.mp3` | Ambient cosmic music bed that plays under the voices |
| `presentation.mp4` | A 720p video render of the presentation (sharable as a video file) |

## Local preview

Just open `people-space-cosmic.html` in any modern browser. Click **Begin the journey** and scroll.

## Deploy to Netlify (via GitHub)

1. Push this repo to GitHub
2. In Netlify, click **Add new site → Import from Git**
3. Pick this repo. No build command needed; **publish directory** = `/`
4. Deploy

The site will serve the presentation at the root URL.

## Controls inside the presentation

- **Scroll** to advance chapters (auto-snaps)
- **Auto-play** button (bottom right): when on, each chapter advances when its voice-over finishes
- **↑ / ↓** keyboard arrows to step through chapters
- **R** to restart from the top
